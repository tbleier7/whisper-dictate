## Global Hotkey — Hold to Record [DONE]
Acceptance criteria:
- [x] Hotkey is read from config.hotkey — no code change required to reconfigure
- [x] Holding the hotkey while in IDLE state transitions to RECORDING state
- [x] Hotkey has no effect during LOADING (or any non-IDLE) state
- [x] Audio is captured via sounddevice.InputStream at 16 kHz mono float32 for the full hold duration
- [x] RMS amplitude is computed per audio chunk and fed to window.push_amplitude()
- [x] Releasing the hotkey stops audio capture; captured audio passed to _transcribe() stub
- [x] _transcribe(audio: np.ndarray) stub returns to IDLE — wired for Whisper model in next section
- [x] HotkeyManager.stop() / AudioRecorder.stop() called on app exit via QApplication.aboutToQuit

## Language Support [DONE]

Acceptance criteria:
- [x] Config stores `languages` list (array of language codes) and `active_language` (currently selected) — read on startup, saved on clean exit
- [x] Active language label displayed in the floating window during IDLE, SUCCESS, and FAILURE states (uppercased, e.g. `DE`, `EN`, `JA`)
- [x] Clicking the language label in IDLE state cycles to the next language in `config.languages`; language change is immediate and reflected in the window label
- [x] Language change persisted to `config.json` on window close (via `Config.save()` in `FloatingWindow.closeEvent`)
- [x] Selected language code passed to `WhisperEngine.transcribe()` at transcription time so faster-whisper uses the correct language model hint
- [x] Additional languages can be added via `config.json` without any code change; cycling wraps around after the last entry
- [x] Language label is non-interactive during LOADING and RECORDING states (guarded by `if self._state != AppState.IDLE: return`)

Implementation notes:
- All functionality was implemented incrementally across the Floating Window and Whisper Model sections
- No separate files were required; language state lives in `Config.active_language` and the UI in `FloatingWindow._cycle_language()`

Files modified (verified complete):
- whisper_dictate/config.py  — `languages` and `active_language` fields; persisted via `save()`
- whisper_dictate/window.py  — `_cycle_language()` updates config; label shows `active_language.upper()`
- whisper_dictate/app.py     — `_on_recording_stopped()` reads `config.active_language` at transcription time
- whisper_dictate/model.py   — `_TranscribeThread.run()` passes `language=self._language` to `model.transcribe()`
